# Contributing

Contributions are subject to the project’s [MIT license](LICENSE) and applicable third-party catalog terms. Read [AGENTS.md](AGENTS.md) and [Getting started](docs/GETTING_STARTED.md).

Describe the problem and approach, keep changes focused, preserve local data and Health permissions, and include focused tests. Run relevant checks in [Testing](docs/TESTING.md), report exact outcomes and disclose schema or serialized snapshot compatibility risks. Use synthetic fixtures only; do not include Health samples, personal logs, provisioning profiles or signing credentials. Never reset a real store or deploy to a device without the owner's explicit approval.

Open a pull request using the template after the repository owner enables contributions. Do not change capabilities, bundle identifiers, signing or network behavior without review.
