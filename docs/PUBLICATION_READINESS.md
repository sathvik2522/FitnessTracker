# Publication notes

This repository is a sanitized source snapshot. It contains no raw device containers or personal Health records; local device and signing receipts are excluded. The existing widget App Group is owner-specific and must be configured consistently for other teams.

The project uses an MIT license; bundled third-party catalogs have separate license requirements. The unsigned simulator build and 216 hosted unit tests passed locally. The proposed GitHub Actions workflow has not been run on GitHub. See [testing](TESTING.md) and [current state](CURRENT_STATE.md).
