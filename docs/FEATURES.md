# Features and limitations

- **Today:** local-day nutrition totals, estimated energy/balance, steps, workout and weight summaries, date selection and configurable goals.
- **Food:** local saved foods, meals/recipes, portions, meal diary, offline search, recent/favorites and immutable historical nutrition snapshots.
- **Training:** exercise library, saved routines, resumable sessions, sets and progression, cardio and stair climber; manual records remain separate from Apple Health.
- **Progress:** local-day ranges, native charts, nutrition, activity, body-weight and workout details; empty and partial readings remain explicit.
- **Health:** opt-in, read-only activity, optional sleep and optional HRV SDNN/resting-heart-rate reads. Widgets use privacy-controlled local snapshots.

Not implemented: Android, cloud sync, app accounts, paid food API, in-app restore, Health writes or guaranteed background refresh. Physical Health reconciliation and real VoiceOver remain unverified. The advanced scoring research code is not a replacement for the displayed model; see [scoring](SCORING.md).
