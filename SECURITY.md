# Security

Do not disclose suspected security issues, credentials, personal Health information or private data in public issues. If GitHub private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** action; otherwise contact the repository owner privately through an existing trusted channel. No response-time guarantee is currently established.

Do not upload device containers, diagnostic logs, profiles, certificates or screenshots with real data. A local data export is sensitive and has no implemented restore. See [data and privacy](docs/DATA_AND_PRIVACY.md).
