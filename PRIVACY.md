# Privacy

PersonalFitness is designed for local use: no app backend, account, analytics service or paid nutrition API is required. Food, workouts and manual weights are persisted locally; optional HealthKit reads require user action. Widgets can use a shared local App Group snapshot and default to hiding values. iOS system backups, Apple Health and the Files destination of an explicitly requested export have their own behavior and settings.

Deleting the app can remove local records; JSON export is not an in-app restore. Health data remains governed by Apple Health. See [data and privacy](docs/DATA_AND_PRIVACY.md) for scope and limitations.
